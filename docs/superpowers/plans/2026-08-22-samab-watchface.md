# SamABSwatchFace Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Watch Face Format v2 watch face for the Galaxy Watch 5 Pro reproducing the approved mockup (black/blue digital face with weather, forecast, health row, dual battery), built as a sideloadable APK.

**Architecture:** Pure declarative WFF v2 — one Gradle module `watchface/` with `res/raw/watchface.xml` holding the entire face, no runtime code (`hasCode=false`). Static art (bezel ticks, blue arcs, dividers, weather icons) is generated by a committed Python/Pillow script. Non-native data (sleep, sleep score, distance/kcal, phone battery) are styled complication slots.

**Tech Stack:** Watch Face Format v2, Android Gradle Plugin 8.5.2, Gradle 8.9, Java 17, Python 3 + Pillow for asset generation, adb for install.

**Spec:** `docs/superpowers/specs/2026-08-22-samab-watchface-design.md`

- [ ] **Step 1: Write `tools/gen_assets.py`** — Pillow, draws at 4× supersampling then downscales with LANCZOS. Structure:

```python
#!/usr/bin/env python3
"""Generate static drawables for the SamAB watch face."""
from PIL import Image, ImageDraw
import math, pathlib

RES = pathlib.Path(__file__).resolve().parent.parent / "watchface/src/main/res/drawable-nodpi"
S = 4  # supersample
BLUE = (59, 130, 246, 255)

def canvas(w, h):
    return Image.new("RGBA", (w * S, h * S), (0, 0, 0, 0))

def save(img, name, w, h):
    img.resize((w, h), Image.LANCZOS).save(RES / name)

def gen_bg():
    img = canvas(450, 450); d = ImageDraw.Draw(img); c = 225 * S
    for i in range(60):
        a = math.radians(i * 6 - 90)
        major = (i % 5 == 0)
        r1 = (225 - (14 if major else 8)) * S; r2 = 223 * S
        col = (255, 255, 255, 230 if major else 100)
        d.line([c + r1*math.cos(a), c + r1*math.sin(a),
                c + r2*math.cos(a), c + r2*math.sin(a)],
               fill=col, width=(3 if major else 2) * S)
    box = [c - 218*S, c - 218*S, c + 218*S, c + 218*S]
    d.arc(box, 200, 340, fill=BLUE, width=4 * S)   # top arc
    d.arc(box, 30, 150, fill=BLUE, width=4 * S)    # bottom arc
    for y in (210, 312):
        d.line([60*S, y*S, 390*S, y*S], fill=(255, 255, 255, 50), width=1 * S)
    d.line([65*S, 208*S, 385*S, 208*S], fill=BLUE, width=2 * S)
    save(img, "bg.png", 450, 450)
```
Then icon functions (each 64×64 logical): `wx_clear` (circle + 8 rays), `wx_partly` (small sun top-right behind cloud), `wx_cloudy` (cloud = 3 overlapping circles + rect, outline style), `wx_rain` (cloud + 3 slanted lines), `wx_snow` (cloud + 3 dots), `wx_thunder` (cloud + bolt polygon), `wx_night` (crescent = filled circle minus offset circle + 2 small star dots), `wx_night_cloud` (crescent + small cloud), `ic_link` (two interlocked rounded rects, blue), `ic_shoe` (sneaker silhouette polygon, green #22c55e), `ic_watch` (rounded-rect watch body + strap stubs, white), `ic_phone` (rounded rect + dot, white), `ic_sleep` (crescent, #7c5cff, + two small "z" polylines). Every function follows the `canvas/save` pattern above with simple geometric shapes — keep each under ~15 lines; `main()` calls all and prints each file written.
